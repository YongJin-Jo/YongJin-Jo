웹과 앱을 만들고, 실제 사용 환경에서 발견한 문제를 개선합니다. 학원 운영 웹·앱과 키오스크 서비스를 개발하며 화면 설계부터 출시와 유지보수까지 경험했습니다.

### 하고 있는 일

- **제품 개발** — 운영 웹, 모바일 앱, 키오스크와 Windows 런처를 만듭니다.
- **성능 개선** — 대용량 목록과 번들 크기처럼 사용자가 체감하는 문제를 측정하고 해결합니다.
- **기록** — 문제의 원인, 선택한 방법, 결과를 다시 살펴볼 수 있게 정리합니다.
